# Source Permissions and Release Boundary

Checked against primary sources on 2026-10-15.

## Dataset and Code Are Not the Same License

The TwiBot-22 paper, Appendix A.6, Licensing, states that the dataset uses
CC BY-NC-ND 4.0, while the evaluation framework code uses MIT:

https://arxiv.org/html/2206.04564v4

The source evaluation repository is:

https://github.com/LuoUndergradXJTU/TwiBot-22

The MIT license in this repository covers author-owned code and
documentation only. It does not relicense historical posts, profile
descriptions, third-party software, model weights, or transformed content.
Code availability must not be cited as permission to redistribute source
data or modified source material.

## Current Public Boundary

The reproducibility package distributes reindexed predictions, aggregates,
figure inputs, code, and integrity hashes. It does not distribute raw posts,
profile descriptions, source account/tweet identifiers, generator prompts,
or model checkpoints. The source-derived and generated trajectories are
not being newly released as unrestricted MIT datasets.

This boundary reduces disclosure but is not a legal determination that
every derived artifact is covered by an applicable permission. Retain the
source access terms and obtain clarification from the provider or the
institution where needed.

## Author Confirmation Before Submission

- Confirm the source acquisition/access terms used for the retained data.
- Confirm the permitted research transformations and artifact distribution.
- Confirm model-weight and third-party dependency terms.
- Confirm the institutional ethics/consent determination or exemption.
- Obtain both authors' approval of the final disclosures and release.

These confirmations remain pending. Do not assert that permissions or an
ethics exemption have been obtained merely because the data were public.
